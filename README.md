
# Immersive Luxury Fashion Store

A premium storefront demo for ladies' and gents' unstitched fabrics.

## Website files

- `index.html` — storefront
- `style.css` — website design
- `store.js` — product listing and WhatsApp order enquiries
- `admin.html` — product management page
- `admin.css` — admin styling
- `admin.js` — add, edit, delete and export products
- `README.md` — project information

## Publish with GitHub Pages

1. Upload all seven files to the repository root.
2. Open Settings, then Pages.
3. Select Deploy from a branch.
4. Choose `main` and `/(root)`, then Save.
5. Open the website link provided by GitHub Pages.

The admin page is available at `/admin.html`.

## Important limitations

This is a front-end demo. Admin changes are saved in the
current browser only and do not update the public catalogue
for other customers. A secure shared admin requires a backend,
database, authentication and suitable security rules.

WhatsApp ordering sends an enquiry; the website does not
process payments or automatically confirm orders.

Sample photos, prices and product details are examples.
Replace them with actual fabric photos, accurate prices and
confirmed stock before selling.
